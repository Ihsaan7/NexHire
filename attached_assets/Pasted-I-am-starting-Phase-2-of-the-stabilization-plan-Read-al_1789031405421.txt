NAVIGATION / LAYOUT NOT RE-RENDERING ON ROUTE CHANGE

Problem: When navigating back to a previous route, the URL
updates correctly but the screen still shows the old page's
layout until a manual refresh.

Root cause is likely one of these — check which applies:
- Layout component is not re-mounting on route change because
  it sits above the router outlet and holds stale state
- useRouter().push() is being used but the receiving page
  is not reacting to the new route params/pathname
- A shared layout wrapper is caching the previous render

Fix:
- Add `key={pathname}` to the top-level layout or page
  wrapper so React fully remounts on route change:
  import { usePathname } from 'next/navigation';
  const pathname = usePathname();
  <div key={pathname}> ... </div>
- If using Next.js App Router, verify that each page.tsx
  is a proper Server or Client Component and not sharing
  stale closure state with a parent layout
- If using pages/ router, ensure _app.tsx passes
  router.asPath as key to the Component:
  <Component key={router.asPath} {...pageProps} />
- After fix, verify: navigate forward, hit back button,
  confirm screen updates immediately without refresh
- Also verify no infinite re-render loops are introduced
